# Echoes of Arkanis 🌌

**Echoes of Arkanis** is an ambitious open-world space exploration game built for the web. Inspired by the sense of wonder in *Outer Wilds*, the scale of *No Man's Sky*, and the epic atmosphere of *Star Wars*, this project aims to create a seamless journey across the cosmos.

## 🚀 The Vision

Our goal is to build a massive, persistent universe where players can transition from deep space combat to planetary exploration without interruptions. It's a project focused on the thrill of discovery, the danger of the unknown, and the legacy of ancient civilizations.

### Key Pillars:
- **Interstellar Travel:** Pilot your starship across vast solar systems and jump between different universes.
- **Atmospheric Re-entry:** Experience the transition from the cold vacuum of space to the vibrant surfaces of diverse planets.
- **Missions & Narrative:** Engage in high-stakes space missions, dogfights, and ground-based objectives.
- **Dynamic Physics:** A custom engine focusing on orbital mechanics, realistic planetary scales, and advanced ship handling.

## 🛠️ Technology Stack

The project is developed using modern web technologies to ensure accessibility and performance directly in the browser:

- **Logic:** JavaScript (ES6+)
- **Rendering:** Three.js / WebGL for high-performance 3D graphics.
- **Styling:** Custom CSS3 for immersive UI/UX.
- **Core:** HTML5

## 🚧 Current Development Status

## 🕹️ Getting Started

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Boschi404/Echoes-of-Arkanis.git
   ```
2. Open `index.html` in any modern web browser (Chrome, Firefox, or Edge recommended).
